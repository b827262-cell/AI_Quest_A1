# Security Acceptance Matrix（main 基線）

此矩陣將威脅映射到可執行的測試或腳本。狀態描述的是 main 上可找到的測試覆蓋，不代表本文件工作執行了所有 gate，也不代表 live 平台驗證已完成。所有測試使用合成身份、fake provider、generated key 與 throwaway DB；禁止正式憑證／資料。

## 執行入口

| Gate | 命令／位置 | 頻率 | 綠燈條件 |
|---|---|---|---|
| G-ROOT | `env -u DATABASE_URL corepack pnpm install --frozen-lockfile && corepack pnpm build && corepack pnpm lint && corepack pnpm typecheck && corepack pnpm test` | 每個相關 PR；release 前 | 全命令 exit 0；沒有忽略失敗的安全測試 |
| G-STUDENT | `corepack pnpm --filter AI-Stu-R1 test`，及 `corepack pnpm student:auth-smoke`、`corepack pnpm student:dashboard-smoke`、`corepack pnpm rag:smoke`（依 `docs/STUDENT_AUTH_RAG_OPERATIONS.md`） | Student auth/RAG 變更；release 前 | 合成 Access fixture、session、scope、RAG contract 全過；live Access/provider 僅在 Owner 授權後另記結果 |
| G-AUTH | `corepack pnpm --filter @ai-smartbook/auth test`、`corepack pnpm --filter AI-adm-D1 test` | auth / Admin API PR | boundary、session、CSRF、錯誤 envelope、bundle 測試全過 |
| G-SITE | `cd site && npm ci --ignore-scripts && npm run typecheck && SITE_TARGET=backend GIT_SHA="$(git rev-parse HEAD)" npm test && SITE_TARGET=backend npm run site:preflight`（`npm test` 會先 build + size gate） | site/relay/topology PR；逐站部署前 | Worker health role/site 對應 target；preflight project id 與 target 一致。當前 hosting manifest 只含 backend，student/admin preflight 按 runbook 預期阻擋 |
| G-OPS | `scripts/release-gate-student-rag.ts`、`scripts/release-artifacts.mjs`；依部署 runbook 做只讀 GET 與 capture | 發版前；平台變更後 | release metadata 連到 commit SHA；secret scan 對該 gate 範圍通過；不要把 commit SHA 誤當成編譯產物 digest。沒有未授權 deploy/migration/secret 操作 |

> 執行時以當前 package scripts 為準。此處只列文件與 package manifest 可證明的入口；未找到 GitHub Actions workflow 自動執行以上命令的證據（`.github/CODEOWNERS` 是 repository ownership，不是 workflow）。

## 每案可判定的測試條件與事件

| Case | Test level / safe fixture | Expected status or pass/fail rule | Required event / logging rule |
|---|---|---|---|
| AC-01 | HTTP integration；generated Access signing key/JWKS、隨機 cookie、throwaway DB | invalid/missing/expired assertion 或 session → 401 且沒有新 session；缺 config/cert service → 503；pass iff status、cookie、session rows 全符合 | 不記 assertion、cookie 或 session token；目前 Student 專用 auth audit event 未確認 |
| AC-02 | HTTP integration；兩個不同 session token、token-substitution cookie、可控 request barrier | revoked/expired replay 與跨 Admin/Student cookie → 401；登出後續請求 → 401；race 結果需有明確規格與測試才可 PASS | Admin `admin.auth.logout`；Student logout event 未確認；禁止記 raw token |
| AC-03 | UI integration；fake timer + 多個同時 401 fetch | 同一過期 session只造成一次登入狀態清除/redirect，沒有重試風暴；403/404/5xx 不登出 | 不新增 token-bearing client log；目前並行 401 case 缺失 |
| AC-04 | HTTP/package integration；synthetic student A/B、book A/B、published/unpublished fixture | body scope override → 400；未知/不可見 resource → documented 403/404；不得回其他 student/book 的 row/chunk/citation；無 evidence → abstain | 如需 audit，只記 actor ID、route class、結果；不得記問題全文或其他學生資料；IDOR audit 未確認 |
| AC-05 | Admin HTTP + Site relay unit/integration；synthetic identities、generated relay keys | unauth/Student Admin access → 401；bad origin/CSRF/relay → 403 或 guest/rejected；只有 exact allowlist 可成 admin；Sites ingress 外部 header stripping 尚需平台 test；相同 signed GET 在 300 秒窗內可重播，列為目前限制 | 既有 Admin auth/mutation 與 `relay.verify` allowlisted events；不得記 email/token/key 原文 |
| AC-06 | HTTP + component integration；incomplete profile、missing book、expired session、fake provider outage | 每個 fixture 依序為 403、404、401、5xx；UI 的 session-expired 狀態只對 401；其他狀態保留其錯誤分類 | 不要求新增業務內容 log；若有事件僅記 error code/status，避免 query/body |
| AC-07 | AI unit/application integration；inert injection text、fake provider、synthetic retrieved chunk | known query injection → blocked；unsupported claims → unverified/abstained；沒有工具路徑可執行任意操作；新工具必須測 allow/deny | 只記 allowlisted reason / safe diagnostics；不得記 provider credential；Question/answer log 需 redacted + bounded |
| AC-08 | Upload/parser integration；小型 crafted-but-benign PDF、malformed PDF、fake parser/provider | bad type → 400/415，oversize → 413；錯誤不含 stack/path；parser CPU/memory isolation 未實作前標為 GAP，不得宣稱 PASS | 固定 cleanup warning 不含 path；parser failure event 不應含原始文件內容 |
| AC-09 | 無 current runtime fixture；若新增 QM adapter 才建立 tenant A/B workspace | 現況標 N/A；新 adapter 要證明 A 不能讀 B 的 memory/file/keychain/run trace，deny status 確定且無資料輸出 | 新 adapter 必須定義 audit fields/retention；不得記 keychain value 或 secret |
| AC-10 | Boundary/build/API integration；唯一用途的 synthetic secret marker | marker 不出現在 browser bundle、response、stdout/stderr 或被掃描 artifact；Student exception response 需 fixture 確認不含內部 detail；每個 scan 有明確 exit 0/非 0；全域 Git history / compiled-artifact scan 尚缺 | Admin audit + safe diagnostic allowlist；AI content pattern redaction；掃描錯誤不可印 secret value |
| AC-11 | HTTP multipart integration；mkdtemp root、synthetic PDF/PNG、`../`/反斜線檔名 | final resolved path 必須留在 upload root；錯 MIME/signature/extension → 400/415；limit → 413；失敗後 pending/output file 數為 0 | cleanup warning 固定字串；不記上傳內容或絕對 path |
| AC-12 | Unit/adapter integration；Cerebras fake DNS + injected transport；generic-provider stub fetch with synthetic Admin config/credential | Cerebras 對 loopback/private/link-local/metadata DNS answer、unsafe scheme/redirect 在 credential write 前拒絕；generic provider 也應證明同等限制；timeout/oversize 有界；不得觸碰真實內網。現有 generic-provider URL 負向測試缺口 | 記 provider ID、failure kind、reason code即可；不記 base URL credential 或 Authorization |
| AC-13 | DB/API integration；throwaway DB + marker password/key + synthetic Q&A | auth/mutation row 出現；metadata/body 無 secret marker；AI log 長度 bounded 且 pattern redacted；tamper/retention 無證據即列 GAP | `admin.auth.login.*`, `admin.auth.logout`, `admin.request.mutation`; AI prompt/answer redacted;不記 cookie/API key |
| AC-14 | Static + isolated package/release check；lockfile diff、test-only install-script metadata、temporary output dir | frozen install 可重現；來源/integrity/版本變更可審；release metadata 對應預期 commit SHA；沒有實際 workflow 的項目標 manual，commit SHA 不代表 artifact digest | release/audit 結果只存摘要，不存 secret；目前沒有 supply-chain workflow event |

## Fixture／環境需求交接

1. **Identity:** `apps/AI-Stu-R1/server/student-auth-routes.integration.test.ts` 自產 RSA keys/JWKS；Admin tests 建立 throwaway SQLite sessions；Site relay tests 用 synthetic identity/key。不能把生成 fixture key 複用到部署。
2. **Scope:** 建立 student A/B、book A/B、published/unpublished rows；RAG provider 用 fake adapter；無 teacher/classroom API 時不建立假的 endpoint。
3. **AI:** 對 injection 用 inert文字 fixture；對 SSRF 用 fake DNS resolver / injected transport；不打真實 provider。檢查 provider credentials 僅由 server resolver 讀取。
4. **Uploads:** 每個 test 建 `mkdtemp` upload root；測試 traversal 只能驗證 sanitizer/最終路徑仍在 root；內容是小型 synthetic PDF/PNG；測完遞迴清除。
5. **Sites:** role/site preflight 讀 build artifact；secondary hosting project id 目前有文件化限制。O-1a 需要 Owner 授權的 staging 平台測試，本票沒有執行，也不能以 unit test 代替。
6. **Supply chain:** dependency diff 審查使用 lockfile-only diff、registry/integrity/script metadata；禁止在 fixture/CI 中放可自動執行的 exploit 或 production credential。
