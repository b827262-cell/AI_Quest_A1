* `PACKAGE_SHA` — aggregate defined by `site/scripts/verify-upload-package-size.mjs`:
  SHA-256 over the sorted concatenation of `path\0bytes\0sha256(file)\n` for every
  file under the upload root. It is content-order independent, so any added,
  removed, or edited build output changes it.
* `ROW_SET_DIGEST` — SHA-256 of the ordered `[path, bytes, sha256]` rows; pins the
  per-file set including ordering, which `PACKAGE_SHA` normalises away.
* `MANIFEST_SHA` — SHA-256 of `af22d5ad22b734ad0c15ff51ba161b1e7b7b8654.package-manifest.txt`
  (99 rows, `<sha256>  <bytes>  <path>`).
